# newUI — B6 "Split Deck" integration brief

## 1. Goal

Port the approved dashboard UI mock `newUI/reference-b6.html` (frozen copy of the
B6 Split Deck; live version also at `dev/ui-variants/variant-b6.html`, served on
port 4123) into the real gpio-companion apps, replacing the current dashboard
chrome with the Split Deck shell:

- Icon rail with labels (Work / Fleet / T3 / You) → Project / Devices / T3 / Profile
- Context sidebar (repos+files · boards+device pages · sessions · profile sections)
- Split stage: code/file viewer ◧ + live board view ◨ (`⌘1`/`⌘2` focus)
- Resizable bottom console dock (Console / GPIO / Flash / Problems-expert), drag
  handle, persisted height, double-click reset
- `⌘K` command palette with working filter (navigation + board actions)
- Mobile: top bar collapses to logo + short brand + 🔍 + Easy/Expert; sidebar
  becomes a slide-over drawer (☰, backdrop, auto-close on select)

## 2. Targets (all three — feature parity is LOCKED 2026-09-14)

1. `apps/dashboard` — Frame Master `cloudflare-nextjs`, Cloudflare Pages. This is
   the reference implementation. Commands: `bun run typecheck`, `bun run build`.
2. `apps/desktop` — Tauri + Vite (`bun run typecheck`, `bun run build`).
3. `apps/mobile` — Expo (`bun run typecheck`). Native shell: rail → bottom tabs
   is NOT allowed to add a 4th primary item; keep Project/Devices/Profile IA and
   map the deck pieces onto it (see §6).

Mirror UX; do NOT share React files between apps (locked rule).

## 3. Constraints (locked — do not renegotiate)

- App shell stays 100dvh overflow-hidden, compact top bar, flex-1 inner scroll,
  no duplicate page h1/subtitles (locked 2026-09-17, see `PRODUCT.md` + memory
  `dashboard_app_shell`).
- Easy/Expert IA unchanged. Expert-only: UUID/URL, T3 pair, companion info, raw
  keys, Problems tab. Use existing `ExpertGate` (dashboard) / equivalents.
- i18n: English + French, typed catalogs in `packages/core/src/i18n` (`en.ts`,
  `fr.ts`, one `LOCALES` line per language). No hardcoded UI strings. T3 embed
  and API wire strings stay English.
- Mobile ≤899px (`useMobile()`): BottomNavigation stays Project/Devices/Profile,
  `viewport-fit=cover`, safe-area insets, `px-3 py-4` content, `p-4` papers,
  UUID/URL `break-all`, Pair dialog `fullScreen`, Requests Accept/Reject stack.
- T3 tab keeps the keep-alive same-origin iframe; never unmount it on tab switch.
- Bun for web/scripts. No new runtimes. Follow repo `AGENTS.md` + `PRODUCT.md`.
  PRODUCT.md is raw-idea status: do not invent product claims beyond it.

## 4. Source map (mock → real code)

Full mapping in `newUI/route-map.md`. Highlights:

- Sidebar repos/files → existing `ProjectBrowser`, `PcbViewer`, `BreadboardViewer`
- Board cards/actions → existing `DeviceBoardCard`, `FlashPanel`,
  `FlashProxyButton`, `T3PairingPanel`, `GpioPanel`, `DeviceCompanionInfo`
- Pair → `PairForm`; WiFi → `WifiBleForm`; Debug → `DeviceDebugPanel`/`DebugLog`;
  Docs → `DocsMarkdown` + `documentation/user/*`; Requests → `NotificationCenter`
- Dock console → `LiveConsole` (WebSocket `wss://…/v1/console`, no HTTP poll);
  GPIO tab → `GpioPanel`/`GpioHeader`; Flash tab → `FlashPanel` status
- Credits → `/profile/credits` flow (PayPal packs $5/$10/$25/$50, $1 stub is
  admin-only); Keys → `KeysForm`
- Board selection stays shared (`gpio-companion-selected-board`, legacy T3 key);
  T3 selector + Docs stay keyed to the selected board

## 5. Scope

IN: shell (rail/sidebar/split/dock/palette/drawer/status), all pages listed in
`newUI/spec.md` §3, Easy/Expert gating, EN+FR strings, light polish of moved
components only.
OUT: new backend routes, billing changes, firmware, Tunnel changes, Talk/voice
(removed 2026-09-17 — do not re-add, `/api/voice/*` stays 503).

## 6. Mobile + desktop notes

- Mobile: rail labels stay (compact); sidebar is a drawer; split stacks
  vertically (viewer above live); dock height min 64px; palette full-width.
  Reuse existing BottomNavigation for primary nav — the deck rail maps to the
  same three destinations.
- Desktop (Tauri): same web shell; keep `maxWidth`/padding conventions already
  in `apps/desktop` unless the spec says otherwise.
